# أسرار ستوديو — المونتاج

المحرّك: `python "${CLAUDE_PLUGIN_ROOT}/engine/studio.py" <أمر>`
المشاريع تنحفظ في `Documents/AsrarStudio/projects/<اسم>` (اطبع المسار بـ `studio.py path <اسم>`).

## أسلوبك مع المستخدم
- كلّمه بلهجته وبجمل قصيرة. لا مصطلحات تقنية («أداة الرسم» مو Remotion).
- قل له وين وصلت كل خطوة وكم تاخذ.
- سؤال واحد في كل مرة، وما تسأل إلا اللي يغيّر النتيجة.

## الخطوات

### 0) الفحص (أول مرة)
`studio.py doctor` — إذا فيه ناقص، قل له وش ناقص وخذ موافقته قبل التثبيت. محرّك الرسم: `studio.py setup` (~500 ميقا مرة وحدة).

### 1) أسئلة البداية (سؤال سؤال)
1. وين المقاطع؟ (مسار ملف أو مجلد) — وهل فيه مقطع «مهم» لازم يدخل كامل؟
2. فيه لقطات إضافية (تسجيل شاشة/مراجع) تبيها تطلع فوق كلامك؟
3. الأسلوب: `editorial` (أسود وبرتقالي وليموني — مجلة تقنية) أو `gold` (أسود وذهبي).
4. وش يكتب في بطاقة الختام؟ (مثلاً: «رابط التحميل في قروب التلقرام — الرابط في البايو»)

### 2) المشروع والتفريغ
```
studio.py new <اسم> <مقطع1> <مقطع2> ...
studio.py transcribe <اسم>
```
**افحص المقاطع قبل أي شي:** خذ لقطة من كل مقطع (`ffmpeg -ss 2 -i X -frames:v 1 out.jpg`) — إذا الصورة سوداء والمستخدم قال «أعطيتك صوتي» فالفيديو انميشن كامل؛ إذا مقطعين متطابقين (نفس الحجم/نفس الكلام) لا تكرّرهم.

### 3) التصحيح والقص — اكتب `edit.json` بمجلد المشروع
```json
{"fixes": {"BDF": "PDF", "كلود": "Claude"}, "hot": ["مجاني","الحل"], "drop": [[0.0, 7.7]]}
```
- `fixes`: كلمة غلط → صح (التفريغ يغلط بالعامية ~7٪). كلمة → `""` تخفيها من الكابشن.
- `hot`: الكلمات اللي تتميّز بالكابشن (٢-٣ بكل جملة، الكلمة اللي تحمل المعنى).
- `drop`: مقاطع تنحذف (ثواني المصدر) — **الجمل المعادة: احذف الأولى وخلّ الأخيرة.**
ثم `studio.py cut <اسم>` → يطبع كل كلمة بتوقيتها الجديد. **ابنِ الخطة على هالتوقيتات بالضبط.**

### 4) الخطة — اكتب `timeline.json` بمجلد المشروع
```json
{
  "title": "اسم-الفيديو", "style": "editorial",
  "cuts": [3.42, 7.24],
  "chapters": [{"at": 0, "label": "المشكلة"}, {"at": 15.4, "label": "الحل"}],
  "stickers": [{"at": 5.6, "until": 15.0, "text": "ما يصغر ❌", "x": 160, "y": 560, "rot": 5, "color": "red"}],
  "hero": [{"a": 15.4, "b": 18.7, "emoji": "🍊", "title": "Tangerine", "subtitle": "كل شي في مكان واحد"}],
  "broll": [{"file": "C:/…/ref.mp4", "from": 13.0, "a": 18.8, "b": 22.7, "tag": "اسحب الملف → تطلع الدائرة", "landscape": false,
             "crop": "464:272:0:344", "blur": [16, 162, 430, 368]}],
  "strike": [{"a": 41.6, "b": 46.5, "items": ["convert.com", "compress.io"]}],
  "fix": [{"a": 1.6, "b": 2.8, "zoom": 0.14}],
  "endCard": {"dur": 3.2, "emoji": "📥", "title": "رابط التحميل\nفي قروب التلقرام", "button": "🔗 الرابط في البايو", "sub": "مجتمع أسرار الرقمية"},
  "music": null
}
```
**القواعد (تعلّمناها بالطريقة الصعبة):**
- كل عنصر يطلع **على الكلمة اللي تقوله** (من توقيتات `cut`)، مو على رقم تقريبي.
- `cuts`: أوقات القطع بين المقاطع (أو أي لحظة تبي فيها ضربة زوم).
- `stickers` بقسم المشكلة: ٤-٦ ملصقات، كل واحد مع كلمته، `until` = بداية الحل. الألوان: `red` `lime` `cream` `accent`. خلّها بين y=300 و y=1100 (لا تغطي الكابشن عند 1390).
- `broll`: لما يتكلم عن ميزة، اعرض تسجيل الشاشة اللي يوريها. `crop` لقص جزء من المرجع (w:h:x:y بأبعاد المصدر). `blur` [x,y,w,h] لتغبيش **أي حساب أو وجه أو بيانات شخص ثاني** — إلزامي.
- `fix`: زوم لإخفاء غلطة تصوير (يد دخلت الكادر، اهتزاز).
- **لا تقسم الشاشة ولا تصغّر فيديو المستخدم** إلا إذا طلب — الشاشة كاملة والانميشن فوقها.
- **لا تكرّر نفس الأسلوب لفيديوين ورا بعض** — نوّع الألوان والترتيب.
- المدة المثالية ٣٠-٤٥ ثانية؛ أول ثانيتين أقوى جملة.
- لا تحط صوت مستنسخ ولا موسيقى إلا بطلبه.

### 5) المعاينة — لا ترندر قبلها
`studio.py preview <اسم> 1.5 6 16 25 40 50` → `preview.jpg`. **افتح الصورة وشوفها بنفسك**: نص طالع برا الشاشة؟ عناصر متداخلة؟ ملصق يغطي الكابشن؟ أصلح ثم أعد.

### 6) الرندر
`studio.py render <اسم>` → مجلد `out`: نسخة تيك توك وريلز (12 ميقابت)، نسخة X (8 ميقابت)، ومعاينة مصغّرة للجوال.
قل له: **المعاينة للمشاهدة بس — ينشر النسخة الكاملة، وينقلها بكيبل/PairDrop مو واتساب/تلقرام (يضغطونها).**

### 7) باقة النشر
بعد التسليم اعرض عليه: «تبي وصف تيك توك + تغريدة + رسالة القروب؟» → استخدم مهارة `publish-pack`.

## إذا صار خطأ
- ذاكرة كرت الشاشة خلصت وقت التفريغ → المحرّك ينتقل للمعالج تلقائياً.
- القرص ممتلئ → امسح `%TEMP%/remotion-*` (مؤقتات الرسم).
- مسار عربي يكسر أمر → استخدم المسارات من بايثون، لا تبنيها في bash.

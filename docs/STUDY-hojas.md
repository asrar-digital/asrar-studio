## الفكرة الذكية: Claude بدون مفتاح API
زر «نفّذ» بالموقع يشغّل في الخلفية:
`claude -p "<task>" --output-format stream-json --verbose --permission-mode acceptEdits --append-system-prompt-file AGENT.md --add-dir <studio> <engine> --allowedTools Bash Read Edit Write Glob Grep`
- المهمة تنكتب على stdin (مجلد المشروع + المطلوب).
- يقرأ الأحداث سطر سطر ويعرض نص Claude وأدواته بالموقع («Claude: …»).
- قبل كل تشغيل ياخذ **لقطة احتياطية** للمشروع (تراجع).
- Claude يعدّل ملفات المشروع → الصفحة تقرأ الملفات كل ثانيتين → يظهر التعديل بدون تحديث.
- يدعم OpenCode كبديل.

## ميزات الواجهة (من الصور والكود)
1. **المكتبة**: بطاقات المشاريع.
2. **مشروع جديد**: رفع ملف أو رابط (`grab` بـ yt-dlp) — أوضاع: clips / manual / auto.
3. **صفحة الأسئلة قبل المونتاج** (brief): نوع المقطع (إعلان/قصة/خبر/شرح/بودكاست…)، المنصة، **المقاس 9:16 · 4:5 · 1:1 · 16:9**، الألوان (هوية/من المقطع/أبيض وأسود/ألوان)، اسم الحساب، أسلوب المونتاج بصور.
4. **الاستوديو**: مشغّل بالنص · يسار: النص جملة جملة (تعديل/حذف) · يمين: قوالب كابشن جاهزة ولوحات (ترجمة، صوت، فحص، تصدير، مشاريع) · تحت: **تايم لاين بطبقات** (كابشن، طبقات نص/صور، فيديو، موجة صوت) · أزرار: تراجع/إعادة/قص · «أضف لـ Claude» · «ملاحظة بالصوت» · تصدير.
5. **حلقة طويلة → مقاطع**: يرشّح مقاطع ويعطيها **درجة** (94، 90، 62) + سبب + عنوان، تختار وتبني.
6. **الملاحظات**: تضغط على ثانية بالفيديو وتكتب ملاحظة (أو صوت/لقطة) → Claude ينفّذها ويعلّمها «تمّت».
7. **صيغ هوك متعددة** وتصدير نسخة لكل هوك.
8. **فحص**: الاحتفاظ، الحشو، الإعادات، ومدة المقطع مقابل كل منصة.
9. **باقة نشر** + نشر تيك توك + إشعار للجوال (ntfy).
10. **تعلّم الأسلوب**: يحفظ الخط والألوان والكلمات المصحّحة.

## الدروس لأسرار ستوديو
- القوة مو بالمحرّك — **بالواجهة + زر «نفّذ» اللي يشغّل Claude**.
- الحالة كلها **ملفات JSON بمجلد المشروع** (studio.json، cut.json، notes.json…) والواجهة تقرأها → بسيط ومتين.
- لقطة احتياطية قبل كل تعديل من Claude = أمان للمستخدم.
- الأسئلة قبل المونتاج بصفحة مرتبة بصور بدل أسئلة المحادثة.

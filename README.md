# 🎬 أسرار ستوديو

**مونتاج احترافي لمقاطعك بالذكاء الاصطناعي — داخل Claude Code.**
تعطيه مقاطعك، وهو يقص السكتات، يفرّغ كلامك بتوقيت كل كلمة، يركّب كابشن عربي متحرك، يضيف ملصقات وعناوين وتسجيلات شاشة، ويطلّع لك الفيديو جاهز لتيك توك وريلز وX — ومعه وصف وتغريدة ورسالة قروب.

مجاني بالكامل 🤍 من [أسرار الرقمية](https://asrar-digital.com)

## ⚡ التركيب (دقيقتين)

**المتطلبات:** اشتراك Claude (Pro أو أعلى) و [Claude Code](https://claude.com/claude-code) على ويندوز أو ماك.

داخل Claude Code اكتب:

```
/plugin marketplace add asrar-digital/asrar-studio
/plugin install asrar-studio@asrar
```

بعدها أعد تشغيل Claude Code واكتب:

```
افحص أسرار ستوديو
```

وهو يفحص جهازك ويقول لك وش ناقص (ffmpeg، Node.js، أداة التفريغ) — وما يركّب شي بدون موافقتك.

## 🖥️ الاستوديو بالمتصفح (جديد — مفتوح للجميع)

```
شغّل أسرار ستوديو
```

يفتح لك استوديو كامل على جهازك (`http://127.0.0.1:8810`):
- **مكتبة مشاريع** + رفع المقاطع بالسحب، أو **رابط يوتيوب** ← Claude يطلّع أقوى المقاطع بدرجات
- **إعلان من رابط** ⭐: حط رابط منتجك ← 3 سكربتات بدرجات ← ملقّن وتصوير من المتصفح ← مونتاج بصور المنتج
- **التقدم مباشر** + زر «نفّذ» يشغّل Claude باشتراكك (بدون مفاتيح API) + تراجع
- **الاستوديو**: النص (تصحيح وتمييز)، العناصر، ملاحظات على ثانية معيّنة، فحص المقطع، باقة النشر
- مقاسات 9:16 و 4:5 و 1:1

## 🎥 الاستخدام من المحادثة

```
سوّ لي مونتاج لهذا المقطع: C:\Videos\clip.mp4
```

يسألك ٣-٤ أسئلة (الأسلوب، اللقطات الإضافية، بطاقة الختام)، يوريك معاينة، وبعدها يطلّع:

| الملف | لوين |
|---|---|
| `…-تيك توك وريلز.mp4` | تيك توك · ريلز · شورتس |
| `…-X.mp4` | تويتر / X |
| `…-معاينة.mp4` | للمشاهدة السريعة على الجوال |

وبعدها: «اكتب لي باقة النشر» ← وصف + تغريدة + رسالة قروب.
